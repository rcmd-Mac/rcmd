## Sort these out first

Two decisions come before anything else, and both are about your hardware rather than the software.

The first: does your keyboard have a right Command key? Apple's own do, but compact boards, split boards
and a lot of third-party layouts do not. If yours is missing it, you are not stuck — the Trigger setting
accepts any combination of modifiers — but you should decide what that combination will be before you
start assigning letters, because changing it later means retraining your hands.

The second: do you use multiple Spaces? If you do, open System Preferences, go to Mission Control, and
turn on "When switching to an application, switch to a Space with open windows for the application."
Without it, calling an application parked on another desktop behaves unpredictably, and the fault looks
like the switcher when it is really macOS.

## The ten-minute tick list

- [ ] Confirm which modifier will be your trigger — right ⌘ if you have it, a custom combination if not
- [ ] Enable the Mission Control Space-switching option if you run more than one desktop
- [ ] Open the app once and let the dynamic algorithm see a normal working session
- [ ] Pick the five or six applications you open every single day
- [ ] Pin each of them: focus the app, hold ⌘ + ⌥, press the letter you want it to own
- [ ] Decide HIDE or CYCLE for each pinned app individually
- [ ] Turn off any letter that clashes with a shortcut you already rely on, under Settings → Enabled Keys
- [ ] Leave the switcher overlay visible for the first two weeks, then switch it off
- [ ] Register the $5.99 licence once you know you are keeping it

## The first hour

Resist the urge to assign twenty-six letters. The dynamic algorithm exists precisely so that you do not
have to, and it adapts as your work changes — a static list of everything freezes a snapshot of one
particular Tuesday. Pin the handful that must never move, and let the rest be decided for you.

Spend the hour on repetition instead. Every time your hand reaches for the Dock, stop and use the letter.
That single correction, repeated for an afternoon, is what converts this from a novelty into something you
stop noticing you are doing.

The HIDE and CYCLE choice deserves a moment of thought per application. A messaging client benefits from
HIDE, because pressing its letter a second time gets it off the screen. A letter with three or four
applications behind it benefits from CYCLE, because rotation is faster than remembering which of them the
algorithm currently favours.

## When a key does nothing

| What you see | Where to look |
| --- | --- |
| A letter never responds | Check Settings → Enabled Keys; the letter may be switched off |
| The app comes forward but the desktop does not change | The Mission Control Space option is still off |
| Right ⌘ does nothing at all | Your keyboard has no right Command key — set a custom Trigger |
| A pinned letter will not launch a closed app | Confirm the app is actually on the static list, not just dynamically favoured |
| Pressing the letter hides the app when you wanted rotation | That app is set to HIDE; switch it to CYCLE per-app |
| The wrong app answers a letter | Pin the one you meant with ⌘ + ⌥ so the algorithm stops choosing |

## After the letters are in your fingers

Once the habit is formed, strip the interface back. Hide the overlay, forget the preferences window, and
let the trigger key be the only part of an rcmd mac download you ever interact with. The measure of a good
switcher is how rarely you think about it, and this one gets there faster than most because there is
nothing to think about beyond a single letter.
